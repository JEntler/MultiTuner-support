Guitar tuning comparison

Drop D vs D Standard vs Drop C

Drop D and D Standard are different tunings. Both start with a low D2, but only their sixth strings match. Drop D is D–A–D–G–B–E; D Standard is D–G–C–F–A–D. Drop C takes D Standard and lowers just the sixth string again, to C2.

Check all six notes in your song’s tuning instructions. A low D alone does not tell you which tuning to use.

Start where you are

Which strings do you need to change?

These steps assume your open strings already match the starting tuning. If you are unsure, check them against the chart first.

01 One string changes

Standard → Drop D

Lower string 6 from E2 to D2, one whole step. Keep strings 5–1 at A2, D3, G3, B3 and E4.

See Standard → Drop D string changes →

02 Keep the low D

Drop D → D Standard

Keep string 6 at D2. Lower each of strings 5–1 one whole step: A2→G2, D3→C3, G3→F3, B3→A3 and E4→D4.

See Drop D → D Standard string changes →

03 One string changes

D Standard → Drop C

Lower string 6 from D2 to C2, one whole step. Keep strings 5–1 at G2, C3, F3, A3 and D4.

See D Standard → Drop C string changes →

Already in Drop D and want Drop C? Lower every string one whole step. Starting in Standard instead? Lower string 6 two whole steps, and the other five one whole step. The destination is always C2–G2–C3–F3–A3–D4.

Check the target, then center the meter.

Use a chromatic tuner or a preset with the intended notes. Play one open string at a time and mute the others. Confirm the target note and octave before making small pitch adjustments, then recheck all six strings.

A setup check for lower tunings: strings can feel looser or buzz after tuning down. If you plan to stay in Drop C, suitable heavier strings or an instrument setup may help. Ask a guitar technician about your instrument; the note chart cannot choose a string gauge for you.
